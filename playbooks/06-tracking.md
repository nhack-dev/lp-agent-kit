# 06 計測（UTM・GA4 は任意）

## UTM（どこから来たか）
媒体ごとに別のリンクを配ると、GA4 で「どこから来た人が押したか」が分かります。
```bash
python3 scripts/utm_link.py https://<公開URL>/ --campaign 2026-11-trial
```
X・Instagram・Threads・LINE・メール・YouTube 用のリンクが出ます。プロフィールや投稿に貼るときは、この UTM 付きのリンクを使う。
- campaign は半角英数字とハイフンで、施策ごとに1つ（例 `2026-11-trial`）。
- 同じ媒体で投稿を比べたいときは `--content post1` のように足す。

## GA4（任意）
1. Google アナリティクスで GA4 のプロパティとウェブのデータストリームを作り、測定 ID（`G-` で始まる）を控える。
2. `.env` の `GA4_ID` か JSON の `tracking.ga4_id` に入れて `build_lp.py` を回す（タグは `<head>` の最初に入る）。
3. ボタンが押されると `cta_click` というイベントが送られる（`cta_id` に line-top ／ form-bottom ／ sticky など）。GA4 の「リアルタイム」で自分で押して届くか確かめる。
4. GA4 の画面で `cta_click` を「キーイベント」に印をつけると、申し込みの数として見やすくなる。
5. **プライバシーポリシーに Google アナリティクスを使っていることを書く**（Google アナリティクスの利用規約で求められています。雛形の4項）。

GA4 を使わない場合でも、LINE 公式アカウントの友だち追加数・フォームの回答数で成果は数えられます。
