# 02 訴求の型を選ぶ

型は「読む人の頭の中の順番」に沿って話を並べるための道具です。文章をそのまま埋める枠ではありません。

## 3つの型

### PASONA（パソナ）— 悩みがはっきりしている商品に
| 段 | 中身 | JSON の section |
|---|---|---|
| P 問題 | 読む人の悩みを言い当てる | `list`（label: Problem） |
| A 共感・親近感 | その悩みが起きる理由を、責めずに説明する | `text`（Affinity） |
| S 解決 | 解決の方法とこの商品の仕組み | `points`（Solution） |
| O 提案 | 何が手に入るか・値段・保証 | `offer`（Offer） |
| N 絞り込み | 誰向けか・期限や人数（本当のときだけ） | `text`（Narrow） |
| A 行動 | ボタン | `cta` |

元の形では2つ目の A は「煽り（Agitation）」ですが、不安を強くあおる書き方は読む人の信頼を落としやすいので、このキットでは「共感（Affinity）」として書きます。

### QUEST（クエスト）— 読む人を選び、学ばせてから勧める商品に
Qualify（対象を絞る）→ Understand（気持ちを分かっていると伝える）→ Educate（考え方を教える）→ Stimulate（変わった後を描く）→ Transition（行動へ）。
講座・コンサルなど、説明が要るものに向きます。`text` と `points` を多めに使います。

### 結論先出し（PREP 寄り）— 短く決めてほしい無料オファーに
結論（何がもらえるか）→ 理由（なぜ役に立つか）→ 中身の例 → もう一度結論＋ボタン。
LINE 登録で特典を渡すだけのページは、これが一番短く済みます。

## 選び方
| 状況 | 型 |
|---|---|
| 悩みが分かりやすい・値段がある | PASONA |
| 商品の説明が長い・高額・読む人を選びたい | QUEST |
| 無料の特典で LINE 登録してほしい | 結論先出し |

選んだ型と理由を hearing に1行書く。
