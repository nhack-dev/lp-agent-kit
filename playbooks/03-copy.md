# 03 文章を書く

## ゴール
`content/<名前>.json` ができ、オーナーの OK がある。形は `examples/lp-content.json` を写して使う。

## JSON の部品
| 項目 | 中身 |
|---|---|
| `design` | simple ／ bold ／ soft |
| `meta` | タイトル（32字前後）・説明文（80〜120字）・公開URL・OGP画像・`noindex`（公開前は true） |
| `hero` | 小見出し（eyebrow）・大見出し（headline）・補足（sub）・画像 |
| `cta` | LINE の URL と文言・フォームの URL と文言・ボタン下の一言（micro）・画面下に固定（sticky）・最後の見出しと文 |
| `sections` | 上から順に並ぶブロック。`type` は list ／ text ／ points ／ offer ／ voices ／ faq ／ cta ／ form_embed |
| `footer` | 特商法・プライバシー・問い合わせの URL、広告の注記、事業者名 |
| `tracking.ga4_id` | GA4 の ID（`.env` の GA4_ID でもよい） |

本文の改行：1つで改行、空行で段落。`**ここ**` で太字（1ブロックに1〜2か所まで）。

## 書き方
- 大見出しは「誰の・何が・どうなる」を20〜30字で。
- 1文40〜60字。専門用語を使わない。
- ボタンの言葉は動詞で始め、押した後に起きることを書く（「無料で受け取る」「空き日程を見る」）。
- ボタンの下に不安を消す一言（「登録は30秒」「いつでも解除できます」）。
- よくある質問は聞き取りの「買わない理由」から作る。
- 数字・声・実績は、聞き取りで出どころが確かめられたものだけ。

## 見せる形
JSON ではなく、見出しと本文を上から順に並べた文章でオーナーに見せる（`build_lp.py` で作った HTML を開いて見せてもよい）。
