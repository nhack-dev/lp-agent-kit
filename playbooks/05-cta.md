# 05 LINE 登録ボタン・フォーム

## LINE 登録
1. LINE Official Account Manager の［ホーム］→［友だちを増やす］→［友だち追加ガイド］で URL を取る。
   形は `https://line.me/R/ti/p/%40あなたのID`（`@` は `%40` に置き換える）。
2. JSON の `cta.line_url` に入れる。`line_text` に押した後に起きること（「LINEで特典を受け取る」）。
3. 登録した人にすぐ届くあいさつの文（LINE 側の設定）で、ページで約束した特典を必ず渡す。ページの約束と LINE の中身をそろえる。
4. スマホとパソコンの両方で押して、友だち追加画面が開くか確かめる。

注意：LINE の公式ボタン画像を使うときは、LINE の案内と規約に従う。このキットのボタンは文字だけ（LINE のロゴは入れていない）。

## フォーム
静的な HTML だけでは送られた内容を保存できません。どちらかにします。
- **リンク**：Google フォームなどの URL を `cta.form_url` に入れる（いちばん簡単・軽い）。
- **埋め込み**：`sections` に `{"type": "form_embed", "src": "埋め込み用URL", "height": 900}` を足す。Google フォームなら「送信」→ `<>` の埋め込みの URL。ページが重くなるので、必要なときだけ。

フォームで個人情報を集めるなら、プライバシーポリシーを置く（`09-law.md`）。

## ボタンの数と位置
最初の画面・真ん中・最後の3か所。スマホでは `cta.sticky: true` で画面下にも固定できる（幅 720px 以上では消える）。
